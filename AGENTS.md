# Contributor and coding-agent instructions

- Read `README.md`, `CONTRIBUTING.md` and `docs/DATA.md` before changing data handling.
- The current frontend is `web/`. The project is a static React/Vite site; there is no online AI-analysis backend.
- Preserve the dark ink, neon category colors and readable low-resolution node graphics. Protect mobile usability and support reduced motion.
- Do not invent holdings, edges, returns, ticker mappings or live-data claims. Keep snapshots, transactions, amount intervals, ownership and options distinct.
- Original-source parsing is in `research/v2/pipeline/`; curated manifests are in `research/v2/sources/` and `research/sources.json`.
- Run `npm test` and `npm run build`. UI changes need desktop and mobile verification. Data changes need official filing evidence.
- Never commit credentials, production configuration, private sessions or user data. A merged contribution does not authorize a production deployment.
- Videos have no subtitles unless explicitly requested; retain a clean master and inspect representative frames.
